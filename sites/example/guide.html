วิธีเพิ่มหน้า

ทุกหน้าคือไฟล์ HTML หนึ่งไฟล์ แล้วลงทะเบียนไว้ใน canvas.json — ลบหน้านี้ได้เมื่อไม่ต้องใช้

  1. คัดลอก welcome.html เป็นไฟล์ใหม่ เช่น setup.html แล้วแก้เนื้อหา
  2. เพิ่มบรรทัดใน canvas.json ส่วน boards: 
    { "file": "setup.html", "title": "การติดตั้ง" }
    ไม่ต้องใส่ตำแหน่ง ระบบจะจัดเรียงให้ (แถวละ 3 หน้า)
  3. เปิดเว็บใหม่ — เสร็จ ไม่ต้อง deploy

จัดวางเอง

ใส่ x, y (และ w, h ถ้าหน้าสูงกว่า 1000px) เพื่อกำหนดตำแหน่งบน canvas:

{ "file": "api.html", "title": "API", "x": 0, "y": 1220, "w": 1440, "h": 1400 }

แบ่งเป็นหลาย page

เพิ่ม pages แล้วใส่ "page" ให้แต่ละหน้า — จะมีแท็บด้านบนให้สลับ:

"pages": [{ "id": "p1", "name": "ภาพรวม" }, { "id": "p2", "name": "รายละเอียด" }]

ชิ้นส่วนที่ใช้ได้

classใช้ทำ
.eyebrowป้ายเล็กเหนือหัวข้อ
.leadย่อหน้าเปิด
.cards + .cardการ์ดเรียงกริด
.callout / .callout.warnกล่องเน้น / คำเตือน
ol.stepsขั้นตอนมีเลขวงกลม
.table-wrapครอบตารางกว้างให้เลื่อนได้บนมือถือ
ทุกไฟล์ในโปรเจกต์นี้เปิดให้ทุกคนดูได้ อย่าใส่ข้อมูลลับ
